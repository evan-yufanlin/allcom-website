# 專案檢討版次 規格

狀態：**草案，待負責人確認**

範圍：專案內各機電空間檢討保留先前版次，可檢視、比較、設為目前檢討；不需要時由管理者刪除。
負責人 2026.11.14 確認：主動另存版次（不自動每次存）、刪除限管理者、比較先做自設變電站與給水水理計算。

---

## 1. 目前檢討與版次

- 1.1 **目前檢討**：維持現行做法，「儲存」覆寫；專案總覽顯示其摘要。
- 1.2 **另存版次**：儲存列新增「另存版次」按鈕，輸入名稱（必填，例：「方案 A 三列配置」「11/14 送審版」，40 字內）與備註（選填，200 字內），將當下畫面輸入存成固定版次，之後不可修改。
  - 畫面有未儲存之修改時，另存版次同時儲存目前檢討，避免版次與目前檢討不一致。
- 1.3 **設為目前檢討**：以某版次取代目前檢討；取代前系統先將原目前檢討自動另存為「自動備份 11/14 15:30」，不會遺失。
- 1.4 每項檢討最多 30 個版次（負責人 2026.11.14 確認）；達上限時提示請管理者刪除不需要的版次。

## 2. 頁面

| 路徑 | 內容 |
|---|---|
| `/projects/[code]`（專案總覽） | 各檢討旁顯示「版次（3）」連結 |
| `/projects/[code]/[工具]/versions` | 版次清單：名稱、存檔時間、存檔人、備註、結果摘要；每列「檢視」「設為目前檢討」「刪除」（僅管理者）；勾選兩項後按「比較」（可含目前檢討） |
| `/projects/[code]/[工具]/versions/[編號]` | 版次檢視：與工具相同畫面，唯讀（不可修改、無儲存列），可存 PDF；頁首顯示版次名稱與「設為目前檢討」 |
| `/projects/[code]/[工具]/compare?a=…&b=…` | 兩版次並列比較（第 3 節） |

- 2.1 刪除：僅管理者；需再次確認「刪除後無法復原」。目前檢討不可刪除。
- 2.2 專案成員可另存、檢視、比較、設為目前檢討。

## 3. 比較內容

共同：
- 3.1 頁首並列兩版次名稱、時間、存檔人。
- 3.2 關鍵結果並列，並顯示差異（例：面積 81.4 → 75.6 m²，−5.8）。
- 3.3 輸入差異清單：只列有變動之項目，標示「新增／刪除／修改」。

**自設變電站**
- 3.4 結果：室內淨長、淨深、淨面積、提醒（電度表工作空間、門扇干涉）數量。
- 3.5 並列兩張平面示意圖。
- 3.6 輸入差異：通道條件各項（例：盤前操作通道 1,800 → 1,500）；各列設備（例：「第 2 列：油 3000kVA → 模鑄 2500kVA」「第 3 列：新增 低壓模鑄 IP20 100kVA」）、列方向。

**給水水理計算**
- 3.7 結果：供水轄區、一日用水量 V、一日設計用水量 Vd、總表口徑、各系統水池與水塔容量及檢核結果、3 日（或基準值）檢討結果。
- 3.8 輸入差異：縣市、行政區、基準值地區；各系統之戶數、用水列（用途、面積、人數、器具數）、其他用水、水池與水塔尺寸；3 日檢討設定。

## 4. 資料庫

新增資料表 **project_review_versions**：

| 欄位 | 說明 |
|---|---|
| id | 流水號 |
| project_code、tool | 所屬專案與工具 |
| name、note | 版次名稱、備註 |
| schema_version、input | 輸入格式版本與輸入內容（同目前檢討） |
| summary | 存檔時之結果摘要 |
| created_by、created_at | 存檔人、時間 |
| auto | 是否為「設為目前檢討」時之自動備份 |

- 4.1 專案刪除時，版次一併刪除。
- 4.2 開啟或比較版次時以最新規則重新計算；若結果與存檔時摘要不同（例：法規修正），提示「依現行規則重算，結果與存檔時不同」並並列兩者。

## 5. 測試

- 5.1 `scripts/verify-projects.ts`：輸入差異清單（變電站、給水各至少 3 種變動）、比較結果之差異值。
- 5.2 本機資料庫實測：另存兩版 → 比較 → 設為目前檢討（確認自動備份）→ 管理者刪除；專案成員看不到刪除按鈕；截圖傳負責人確認。
