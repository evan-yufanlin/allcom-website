# 規劃工具使用統計 規格

狀態：**草案，待負責人確認**

範圍：記錄 `/tools/...` 各即時規劃工具之使用情形，供管理者檢視「哪個工具被用、用了幾次、從哪裡來」。
網站整體瀏覽人數（Vercel Web Analytics）暫緩，待負責人方便時於 Vercel 後台啟用。

---

## 1. 記錄哪些動作

每個工具記三種動作：

| 代號 | 動作 | 何時記一次 | 代表意義 |
|---|---|---|---|
| 1.1 開啟 | 進入工具頁 | 每次開啟頁面 | 有人看過 |
| 1.2 試算 | 修改任一輸入欄位 | 每次開啟頁面**最多記一次**（第一次修改時），避免每按一個鍵就記一筆 | 有人實際輸入、試算 |
| 1.3 存 PDF | 按下「存 PDF」 | 每次按下 | 完成一次規劃並留存結果 |

- 1.4 適用工具：即時規劃頁全部 9 個工具（自設變電站、給水水理計算、消防水池、電信室、緊急發電機室、停車場通風、避雷、台電配電場所、變壓器規格查詢）。日後新增工具自動納入。
- 1.5 專案檢討（`/projects/...`）屬內部使用，不記錄；專案存檔紀錄本來就存於資料庫。

## 2. 每筆記錄之內容

| 欄位 | 說明 | 來源 |
|---|---|---|
| 時間 | 記錄時間 | 伺服器 |
| 工具 | 例：substation | 網址 |
| 動作 | 開啟／試算／存 PDF | — |
| 地區 | 國家、縣市（例：台灣 新竹市） | Vercel 依連線自動判斷之概略位置 |
| 來源 | 從哪裡連進來：Google、LINE、Facebook、本站其他頁、直接輸入等（只記網站名稱，不記完整網址） | 瀏覽器提供之來源頁 |
| 裝置 | 手機／平板／電腦 | 瀏覽器資訊 |
| 訪客代號 | 用於計算「幾個人」而非「幾次」；每日更換、無法還原 | 見 2.1 |

- 2.1 **訪客代號**：以「當日日期＋連線 IP＋瀏覽器資訊＋祕密字串」計算雜湊值，**不存 IP**。同一人同一天得到相同代號，隔天即不同，無法跨日追蹤，也無法反推身分。不使用 cookie，訪客不需按同意。
- 2.2 不記錄 IP、姓名、輸入內容（工程名稱、面積等）或任何個人資料。
- 2.3 排除搜尋引擎爬蟲等自動程式；同一連線短時間內大量送出者略過，防止灌數字。

## 3. 排除內部瀏覽

- 3.1 **登入專案自動標記**：於 `/projects` 登入（專案密碼或管理密碼）成功之瀏覽器，加上「內部」記號（有效 1 年）。
- 3.2 **標記網址**：同仁以手機或電腦開啟 `/internal` 一次，該瀏覽器即加上「內部」記號；頁面顯示「本瀏覽器已標記為內部，不列入統計」，並可取消。
- 3.3 有「內部」記號之瀏覽器，使用工具時**不記錄**。
- 3.4 公司固定 IP 整批排除：待確認公司是否有固定 IP 後再加入（IP 存於 Vercel 環境變數，不進 repo）。
- 3.5 無法 100% 排除（例：同仁換新手機又未標記），對趨勢影響輕微。

## 4. 統計頁面（管理者）

路徑 `/projects/stats`，僅管理密碼登入可看；`/projects` 管理者頁加入連結。

- 4.1 期間選擇：近 7 天、近 30 天、本月、上月、今年、全部。
- 4.2 **各工具一覽表**：開啟次數、試算次數、存 PDF 次數、使用人數（依訪客代號）、試算率（試算÷開啟）、完成率（存 PDF÷開啟）。
- 4.3 **每日趨勢**：長條圖，開啟／試算／存 PDF 三色。可選單一工具或全部。
- 4.4 **地區排行**：縣市前 10 名（含國外）。
- 4.5 **來源排行**：Google、LINE 等前 10 名。
- 4.6 **裝置比例**：手機／平板／電腦。
- 4.7 顯示本瀏覽器是否已標記為內部，並提供切換。

## 5. 資料庫與保存

- 5.1 使用第一階段之 Neon 資料庫，新增 `tool_events` 資料表；不需負責人另外設定。
- 5.2 每筆約 200 bytes，每月 1 萬筆約 2 MB，免費方案（0.5 GB）可保存多年。
- 5.3 先全部保存；日後量大時，舊資料改為每日彙總。

## 6. 對外說明

- 6.1 「即時規劃」頁底加一行：「本站統計工具使用次數與概略地區，不蒐集個人資料與輸入內容。」

## 7. 測試

- 7.1 驗算腳本 `scripts/verify-analytics.ts`：來源網站分類（Google、LINE…）、裝置判斷、爬蟲排除、訪客代號每日更換且不含 IP。
- 7.2 瀏覽器實測：開啟工具 → 修改輸入 → 存 PDF，統計頁數字各加 1；標記內部後再操作，數字不變；截圖傳負責人確認。
